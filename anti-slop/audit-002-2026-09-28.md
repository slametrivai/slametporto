# Audit Antislop 002: Admin CMS vs TailAdmin

Tanggal: 2026-09-28
Mode: AFTER
Cakupan: semua halaman `/admin/*` (22 view di `resources/views/admin/`) plus HTML yang dirender controller DataTables di `app/Http/Controllers/Admin/`.
Referensi: TailAdmin free template v2 (Tailwind v4), diambil lewat Context7 (`/tailadmin/tailadmin-free-tailwind-dashboard-template`) dan file sumber `src/css/style.css`, `src/partials/{sidebar,header}.html`, `form-elements.html`, `partials/table/table-01.html`, `partials/buttons/button-0{1,4}.html`.

Design Read: back-office CMS untuk satu admin, bahasa visual TailAdmin (diminta eksplisit, jadi R-30 tidak berlaku), dial ENERGY 1 / RHYTHM 1 / MOTION 1.

## Temuan

### REQ: permintaan user

1. **HIGH: Admin belum memakai TailAdmin, hanya menyebutnya**
   - Layout `admin/layouts/app.blade.php` menulis komentar "TAILADMIN SIDEBAR" tapi markup-nya custom: sidebar `w-64` dengan aktif `bg-indigo-50`, header `bg-white/95 backdrop-blur`, kartu `rounded-xl ... shadow-sm`, input `text-xs` dengan `focus:ring-indigo-500`.
   - Token TailAdmin (`brand-*` #465fff, `gray-*`, `success/error/warning-*`, `shadow-theme-xs`, `text-theme-sm/xs`, `text-title-sm`, utility `menu-item*`) tidak ada sama sekali. Hitungan: 1199 kelas `slate-*`, 397 `indigo-*`, 0 `gray-*`/`brand-*` di area admin.
   - Hambatan teknis: `tailwind.config.js` dipakai bersama dengan situs publik, dan publik sudah memakai `brand-*` sebagai lime (#B8FF3D) serta me-remap `slate-*` ke navy. Token TailAdmin tidak bisa ditaruh di config yang sama tanpa merusak publik.
   - Perbaikan: entry CSS terpisah `resources/css/admin.css` dengan `@config "../../tailwind.admin.config.js"` (fitur Tailwind v3.2+), berisi token TailAdmin v2 dan utility `menu-item*`. Lalu tulis ulang layout (sidebar, header, overlay mobile, breadcrumb) dan 21 view memakai pola kartu/tabel/form/tombol/badge TailAdmin, termasuk HTML badge dan tombol aksi di 8 controller.

### Hard Gate (HIGH)

2. **HIGH: Em dash di teks UI** (R-02)
   - 11 kemunculan: `<title>` layout (`Admin Dashboard — ...`), placeholder sel kosong `—` di `CertificationController.php` dan `PostController.php`, serta teks di `categories/create`, `categories/edit`, `settings/index`.
   - Perbaikan: ganti dengan `|`, `:`, atau `-`/"Tidak ada".

3. **HIGH: Kontras teks sekunder di bawah WCAG AA** (R-25)
   - Config me-remap `slate-400` ke `#8B95A7`: rasio 3.02:1 di atas putih (butuh 4.5:1). Dipakai 88 kali, sering digabung `text-[10px]`/`text-[11px]` (79 kali).
   - Catatan untuk migrasi: `gray-400` TailAdmin (#98A2B3) juga hanya 2.58:1. Teks yang harus terbaca memakai `gray-500` (4.97:1); `gray-400` hanya untuk placeholder dan ikon.

4. **HIGH: Label form tidak terhubung ke input** (R-32, C-4)
   - 98 `<label>` di 13 form, 0 yang punya `for=`/membungkus input. Screen reader tidak membacakan nama field, klik label tidak memfokuskan input.

5. **HIGH: Modal dan sidebar mobile tidak bisa ditutup dengan keyboard** (R-32)
   - Modal detail inquiry (`inquiries/index.blade.php:55`) tidak punya handler Escape dan tidak memindahkan fokus. Sidebar mobile tidak punya overlay (TailAdmin punya `partials/overlay.html`) dan tidak tertutup dengan Escape.
   - Toggle SEO di `posts/*` dan `categories/*` dipasang pada `<div @click>`; tombol di dalamnya tidak punya `aria-expanded`.

6. **HIGH: Target sentuh di bawah 44px** (R-03)
   - Tombol aksi baris tabel `h-8 w-8` (32px) di 8 controller, tombol Logout header `py-1.5 text-xs` (sekitar 28px), tombol tambah/hapus metrik di `projects/*` `p-1.5`.

7. **HIGH: Tombol "Balas via WhatsApp" tidak bisa menjangkau pengirim** (R-26)
   - Tabel `inquiries` tidak punya kolom nomor telepon, jadi link `https://wa.me/?text=...` (dashboard, modal inquiry, `InquiryController` baris aksi) hanya membuka pemilih kontak WhatsApp dengan teks terisi. Label menjanjikan balasan ke pengirim.
   - Perbaikan: hapus tombol WA, atau tambah field telepon di form kontak publik dulu.

8. **HIGH: Ekspor CSV rentan formula injection** (keamanan, di luar rule antislop)
   - `InquiryController::export` menulis `name`, `subject`, `message` dari form publik apa adanya. Nilai seperti `=HYPERLINK(...)` dieksekusi saat CSV dibuka di Excel/Sheets.
   - Perbaikan: awali sel yang dimulai dengan `= + - @` tab/CR dengan `'`.

### Purpose-Gate (MEDIUM)

9. **MEDIUM: Font mono dan label uppercase ber-tracking lebar tanpa alasan** (R-06)
   - `font-mono` di 20 file (angka statistik, tanggal, slug, label "OPERATIONS & SYSTEMS CMS", "Back-Office CMS"); 24 label `uppercase tracking-wider`. TailAdmin memakai font sans biasa untuk semua ini.

10. **MEDIUM: Badge statis tanpa fungsi** (R-09)
    - `settings/index.blade.php:22` menampilkan "RalphJSmit SEO Engine Active" tanpa cek status apa pun. Badge "Needs Attention" di dashboard memakai `animate-pulse` (R-19) tanpa kebutuhan.

11. **MEDIUM: Header blur dan modal blur + shadow-2xl** (R-10, R-12)
    - Header `backdrop-blur`, overlay modal `backdrop-blur-sm`, panel modal `shadow-2xl`. TailAdmin memakai header solid `bg-white` dan overlay `bg-black/50` tanpa blur.

### Quality Locks dan pemeliharaan (LOW sampai MEDIUM)

12. **MEDIUM: Tiga sumber style DataTables saling menimpa**
    - `resources/css/app.css` men-style DataTables dengan `brand-*` (lime) dan `slate-*` (navy), lalu `<style>` inline di layout menimpanya dengan indigo lewat `!important` (sekitar 130 baris), plus CSS CDN `jquery.dataTables.min.css`.
    - Admin juga memuat base publik dari `app.css`: `html` berlatar `#080B12`, scrollbar gelap, seleksi teks lime, di dalam admin yang terang.
    - Perbaikan: `admin.css` sendiri (lihat temuan 1) dengan satu blok style DataTables memakai token TailAdmin; hapus `<style>` inline.

13. **MEDIUM: Alpine `x-data` settings pecah jika meta description berisi baris baru**
    - `settings/index.blade.php:6-10` menyuntik nilai dengan `'{{ addslashes(...) }}'`. `meta_description` diisi dari `<textarea>`; baris baru menghasilkan string JS tak tertutup, Alpine gagal, dan preview SEO berhenti bekerja.
    - Perbaikan: `@js($settings['meta_description'] ?? '')`.

14. **MEDIUM: Tidak ada state error dan UI DataTables berbahasa Inggris** (R-27)
    - Loading ada (`processing: true`), tapi gagal ajax hanya memunculkan `window.alert` bawaan DataTables. Teks kosong/info/paginasi "No data available in table", "Showing 1 to 10" bercampur dengan UI berbahasa Indonesia.
    - Perbaikan: satu `$.extend($.fn.dataTable.defaults, { language: {...} })` dan `$.fn.dataTable.ext.errMode` di layout.

15. **LOW: Identitas admin di-hardcode** (R-38)
    - Sidebar menampilkan "SR / Slamet Rivai / Super Admin" statis, bukan `auth()->user()`. Tidak ada link ke halaman profil yang sudah ada (`profile.edit`).

16. **LOW: Markup tombol aksi tabel diduplikasi di 8 controller**
    - String HTML tombol edit/hapus yang sama (sekitar 6 baris per tombol) disalin di setiap controller. Migrasi ke TailAdmin berarti mengedit 8 salinan.
    - Perbaikan: satu partial `admin/partials/row-actions.blade.php` yang dirender `view(...)->render()`.

17. **LOW: Footer dan komentar dekoratif** (R-31, C-3)
    - Footer "TailAdmin & Yajra DataTables • Slamet Rivai CMS" tidak memberi informasi. Komentar banner `<!-- ====... -->` berulang di layout.

18. **LOW: Dependensi npm tidak terpakai**
    - `jquery` ^4 dan `datatables.net-dt` ^3 ada di `package.json`, tetapi layout memuat jQuery 3.7.1 dan DataTables 1.13.7 dari CDN. Pilih salah satu; yang paling kecil diff-nya adalah menghapus kedua paket npm.

## Keputusan yang perlu dari user

19. **Dark mode TailAdmin**: layout sekarang sengaja memaksa mode terang (`layouts/app.blade.php:25`). TailAdmin punya toggle dark. Jika toggle dipasang, kedua mode wajib diverifikasi (R-34), sehingga setiap view butuh varian `dark:`. Tanpa pilihan ini, migrasi hanya mode terang.

## Catatan

- Aman, tidak perlu diubah: `x-html="activeInquiry.message"` di modal inquiry sudah di-escape di server (`nl2br(e(...))` pada `InquiryController::show`).
- Statistik dashboard berasal dari query DB nyata (R-17 lolos).
- Audit ini tidak mengubah kode apa pun. Temuan 1 adalah inti permintaan; temuan 2 sampai 6, 9 sampai 12, 16 dan 17 otomatis ikut terselesaikan saat view ditulis ulang ke TailAdmin. Temuan 7, 8, 13, 14, 15, 18 adalah perbaikan terpisah yang kecil.

### Revisi: sidebar selalu tampil mulai 1024px

Laporan user: sidebar di `/admin` harus diklik dulu. Penyebab: layout memakai breakpoint `xl` (1280px) dari `sidebar.html`, sedangkan dokumentasi TailAdmin (Context7, ALPINE_COMPONENTS.md) menetapkan sidebar permanen mulai `lg` (1024px). Layout diubah ke `lg:static lg:translate-x-0` dan tombol menu/overlay `lg:hidden`. Form dua kolom di `posts/_form` dan `settings/index` digeser ke `xl` supaya tidak sempit saat konten tinggal sekitar 734px. Build sukses, 47 test lulus. Belum dicek langsung di browser.
